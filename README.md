# Plumbers FC

**Διαχείριση Θερμοϋδραυλικής Επιχείρησης**

Εφαρμογή διαχείρισης πελατών, ραντεβού, υλικών, προσφορών και τιμολογίων για θερμοϋδραυλικές επιχειρήσεις.

Created by Kouskouras Dimitrios.

## Λήψη (Download)

Πήγαινε στην ενότητα **[Releases](../../releases/latest)** και κατέβασε:

- **Windows** → `Plumbers FC Setup 1.0.2.exe` (installer) ή `Plumbers FC 1.0.2.exe` (portable, χωρίς εγκατάσταση)
- **Android** → `app-release.apk` (χρειάζεται να ενεργοποιήσεις "Εγκατάσταση από άγνωστες πηγές")

## iPhone / iPad (χωρίς App Store)

Άνοιξε στο Safari: **https://kouskourasd-creator.github.io/plumbers-fc-releases/**

Πάτα το κουμπί **Κοινή χρήση** (τετράγωνο με το βέλος) και μετά **"Προσθήκη στην Αρχική οθόνη"**. Η εφαρμογή εγκαθίσταται σαν κανονικό app με δικό της εικονίδιο, χωρίς Apple Developer account ή Mac.

Ο πηγαίος κώδικας δεν είναι δημόσιος.
