# Plumbers FC

**Διαχείριση Θερμοϋδραυλικής Επιχείρησης**

Εφαρμογή διαχείρισης πελατών, ραντεβού, υλικών, προσφορών και τιμολογίων για θερμοϋδραυλικές επιχειρήσεις.

Created by Kouskouras Dimitrios.

## Λήψη (Download)

Πήγαινε στην ενότητα **[Releases](../../releases/latest)** και κατέβασε:

- **Windows** → `Plumbers FC Setup 1.0.0.exe` (installer) ή `Plumbers FC 1.0.0.exe` (portable, χωρίς εγκατάσταση)
- **Android** → `app-release.apk` (χρειάζεται να ενεργοποιήσεις "Εγκατάσταση από άγνωστες πηγές")

Ο πηγαίος κώδικας δεν είναι δημόσιος.
