🔧 Πολιτική Απορρήτου — Plumbers FC

Τελευταία ενημέρωση: 08/08/2026

Το Plumbers FC ("η Εφαρμογή") αναπτύσσεται από τον Κουσκούρα Δημήτριο.

Δεδομένα που αποθηκεύονται

Όλα τα δεδομένα που καταχωρείτε (πελάτες, ραντεβού, υλικά, προσφορές, έξοδα) αποθηκεύονται τοπικά στη συσκευή σας. Σε λειτουργία δικτύου ("Network mode"), τα δεδομένα συγχρονίζονται μόνο με server που εσείς οι ίδιοι διαχειρίζεστε στο τοπικό σας δίκτυο — δεν αποστέλλονται σε cloud υπηρεσίες τρίτων.

Τοποθεσία (GPS)

Η λειτουργία δρομολογίου χρησιμοποιεί την τοποθεσία σας μόνο στιγμιαία, τοπικά στη συσκευή, για να δημιουργήσει σύνδεσμο προς το Google Maps. Η Εφαρμογή δεν αποθηκεύει, δεν καταγράφει και δεν αποστέλλει την τοποθεσία σας πουθενά.

Συνημμένα αρχεία

Φωτογραφίες/έγγραφα που επισυνάπτετε σε προσφορές αποθηκεύονται τοπικά στη συσκευή σας (ή στον δικό σας server σε Network mode). Δεν ανεβαίνουν πουθενά αλλού.

Κοινοποίηση σε τρίτους

Δεν κοινοποιούμε, δεν πουλάμε και δεν μοιραζόμαστε δεδομένα σας με τρίτους.

Διαγραφή δεδομένων

Μπορείτε να διαγράψετε όλα τα δεδομένα ανά πάσα στιγμή από Ρυθμίσεις → Δεδομένα → Διαγραφή Όλων, ή απεγκαθιστώντας την εφαρμογή.
